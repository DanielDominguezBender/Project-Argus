# Project Argus

## Objective

Build a small infrastructure operations homelab focused on:

- Virtualization
- Linux administration
- Infrastructure monitoring
- Configuration management
- Automation
- Troubleshooting

## Core Technologies

- Proxmox VE
- Debian / Ubuntu
- Docker
- Ansible
- Icinga
- Grafana

## Hardware

Proxmox Host:

- MacBook Pro Late 2012
- Intel x86-64 CPU
- 16 GB RAM
- SSD storage

## Project Principles

1. Understand before automating.
2. Make small incremental changes.
3. Test every implementation.
4. Document failures and troubleshooting.
5. Keep infrastructure reproducible.
6. Treat the lab as a real operations environment.
